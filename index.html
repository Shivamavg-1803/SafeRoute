Download sample CSV

312 records across 6 fictional areas.

Required CSV format

Header: area,week,report_count. Use 24–520 consecutive weekly dates per area, the same dates for every area, and non-negative whole counts. Up to 20 areas. Missing weeks are rejected.

What the numbers mean

Fit the model to compare its error with a simple baseline.

How this model works

Ridge regression uses each area, the previous week’s count, a four-week mean, a time trend, and seasonal terms. Standardization is learned only from training data. The latest weeks are held out chronologically for one-step-ahead evaluation. After evaluation, the model is refitted on all eligible rows for the next week.

The illustrative band uses the 80th percentile of absolute validation errors across areas. It is not a calibrated confidence interval. MAE means average absolute prediction error; smaller values are better.

ABOUT SAFEROUTE

Built for understanding.
Grounded in transparency.

An individual SDG 5 project by Shivam Mathur.

SDG5

The idea

SafeRoute explores how community information and access to support resources can contribute to women’s empowerment. The concept relates to SDG 5, including Target 5.2 on ending violence against women and girls and Target 5.b on enabling technology. The project does not claim to measure or achieve either target.

Read the UN goal

What this version includes

  • 72 fictional reports in six fictional neighborhoods.
  • A separate 52-week synthetic dataset for regression.
  • CSV validation, model fitting, chronological evaluation, and next-week count estimates.
  • A local report submission and review demonstration.
  • Links to official support and information services.

Privacy, in plain language

There are no trackers, account registrations, API keys, map providers, or background network requests. Demo submissions, local flags, and review choices are stored in this browser. Imported CSVs stay in memory and are cleared when the page closes or reloads.

Anyone using this browser can open the local review workspace. It has no secure sign-in. Never enter real incidents, names, contact information, or exact addresses into this demonstration.
